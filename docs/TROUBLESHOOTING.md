# 常见问题与排查

## 搜索不到节点，或显示缺失节点

确认目录为 `ComfyUI/custom_nodes/Comfyui-prompt-enhancer/`，其中直接有 `__init__.py`，没有多嵌套一层。使用 ComfyUI 的 Python 安装 requirements.txt，重启后端并强制刷新页面。搜索 Samuel-Enhancer，检查后端导入日志。

只保留一个插件副本。0.3.x 旧工作流通过浏览器加载可自动迁移；直接提交旧 API prompt 的客户端需要更新 class_type 或重新导出。

## api_key_env 只能填写环境变量名

该字段填写 `MY_LLM_API_KEY` 这样的变量名，不能填密钥、URL、空格或包含连字符的任意文本。密钥设置在运行 ComfyUI 的后端环境中；修改后端环境变量通常需要重启进程。

无需认证的本地服务可留空。官方接口默认读取 OPENAI_API_KEY，本地接口默认读取可选的 SAMUEL_ENHANCER_API_KEY。

## 服务连接失败、404 或模型名称为空

从运行 ComfyUI 的机器检查服务基础地址与 `/models`。浏览器或另一台机器能访问，不代表 ComfyUI 容器内能访问。

基础地址通常以 `/v1` 结尾，不带 `/chat/completions` 或 `/responses`。model 必须填写服务实际返回的模型 ID。401/403 检查认证与权限；400 还需检查模型、图像支持、高级参数和 JSON Schema 支持。

## 观察、生成或复核阶段输出被截断

接口报告输出触及上限。先提高服务配置中的 max_output_tokens，例如由 4096 提高到 8192。开启思考时可根据上下文和可接受耗时试 16384；每次输入与输出总量须符合服务限制。

若服务支持，可关闭思考以降低开销。llama.cpp 的特定模板可使用 `{"chat_template_kwargs":{"enable_thinking":false}}`，其他服务应采用各自支持的参数。不要同时堆叠未经确认的高级字段。

输出预算与最终正文长度是两种限制，增大预算不会取消 1500 汉字/800 词等篇幅上限。

## 没有返回合法 JSON，或分节字段无效

当前版本要求模型和接口支持 JSON Schema。标准模式生成与精确模式复核均返回分节对象，由程序组装标题；仅外层 JSON 合法不代表正文合格。

确认使用当前完整安装包，前后端已刷新，模板类型与任务匹配。服务若忽略格式参数，返回的旧式字符串仍须符合章节校验。插件不猜测修复缺失内容，不自动追加请求。

## 正文长度超过上限

正文已生成，但最终计数超过所选档位。这种错误不靠继续提高 token 预算解决。

当前执行指导已预留 15% 余量。可精简输入中的重复要求，减少次要细节，或明确要求留在硬上限以内的较低篇幅。必须更短时选择简单版。插件不会直接截断正文，也不会增加额外修复调用。

## 模板与任务不匹配

文本与反推任务连接 generation，编辑指令连接 editing。模板切换会分别保存手稿；恢复默认按钮覆盖当前手稿。升级并不要求重置自己的模板。

## 图片任务失败

确认使用支持图片输入的模型和接口，输入为单张 IMAGE。该版本不支持 MASK、多图批次或多图融合。image_max_side 只控制上传尺寸，不改变实际出图分辨率。

## 生成后手动修改没有生效

选择完整编辑，点击载入原稿按钮后修改 edited_text，再执行下游。仅更改输入框或点击按钮不会自动发起生图。上游更新只刷新原稿预览，不会覆盖你的手稿。

如果希望永久固定提示词，将其复制到独立文本输入节点并断开上游 LLM 分支。

## KSampler 或模型加载报错

检查报错节点和调用栈。若失败发生在采样器、显存管理、量化权重或模型补丁加载阶段，需要排查 ComfyUI、PyTorch、模型与其他节点的兼容性。

例如 `Cannot set version_counter for inference tensor` 应结合模型加载调用栈排查，可参考 [ComfyUI 上游问题记录](https://github.com/Comfy-Org/ComfyUI/issues/15733)。这类错误与提示词字数或 API token 预算属于不同环节。

## 怎样提交反馈

请提供插件版本、ComfyUI/前端版本、服务类型、任务模式、标准或精确模式、报错阶段和脱敏错误文字。可附最小工作流复现。

提交前移除 API Key、私人图片、敏感提示词、内部地址及无关日志。请勿将完整 ComfyUI 用户目录、模型或本地环境作为问题附件上传。

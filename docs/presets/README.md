## 0.3 接入约定

本目录保存已确认的两份模板基线。运行副本位于 templates/presets，逐字节保持一致；完整模板与任务适配规则均在模板编辑器中可见、可编辑并随工作流保存。

默认英文、详细/简单两档篇幅。旧长篇规则、案例和补字要求不参与运行；正文格式与上限由程序检查，超限不截断、不追加调用。负面词完全由下游处理，主节点没有负面词输入输出。需要原文直通时使用普通文本节点。

0.1/0.2 的旧单体节点已移除。新编辑节点只输出四节编辑指令；旧工作流需迁移，不能将其误作旧版六节完整画面描述。

任务路由、阶段 JSON 协议及冲突错误由程序管理。可编辑预设应完整显示实际使用的创作规则，避免隐式叠加旧模板。

后续修订应另存版本并记录变更，以本版作为对照基线。
